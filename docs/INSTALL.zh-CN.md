# 安装、网络与守护

中文 | [English](INSTALL.en.md) | [返回首页](../README.md)

## CommLink 开发版安装

主节点使用原短信 HTTPS 域名及端口 8443。互联电话使用同一证书和主机名的 8444 端口及 `/phone/`，网络必须能独立访问该端口。分别从 Safari 添加到主屏幕，在安卓确认该安装可访问的设备和功能。通讯录及通话记录另需在每台来源设备上启用授权。旧短信安装无需重新配对。请先阅读[升级与验收](COMMLINK-UPGRADE.md)和[语音接入](VOICE.zh-CN.md)。

## Android 首次配置

安装后打开「设置 → 配置检查与自动恢复」。依次设为默认短信应用、授予短信/SIM/通知权限、允许电池优化豁免。联系人权限可选，用于显示联系人名称。MIUI 中另行允许自启动、设置无限制省电策略，可在最近任务中锁定应用。保持 MIUI 优化开启；不同 ROM 的设置名称及效果可能不同。

默认短信模式意味着本应用负责接收和记录文字短信。彩信附件暂不支持；需要完整彩信功能时使用适当的客户端。本机收件箱可用于查看和手动发送文字短信。

## 域名与 HTTPS

1. 准备自己的域名和 DDNS。已验证的路径为：域名 AAAA 指向手机的全球单播 IPv6，不是路由器地址、链路本地地址或 ULA。
2. Cloudflare 记录保持 DNS only。根据路由器能力，仅放行目标手机 IPv6 TCP 8443。不要为本项目开放其他管理端口。
3. 在「域名、证书与 iPhone 配对」填写主机名（如 `sms.example.com`，不带协议和端口）及 Cloudflare Zone ID。
4. 为目标 Zone 创建受限 API Token，授予 Zone Read 和 DNS Edit，通过专用按钮加密保存。不要提交 Token 到 GitHub，不要使用 Global API Key。
5. 阅读应用链接的 Let's Encrypt 服务条款。可先测试 DNS-01，再明确同意并正式签发。应用创建验证 TXT，验证结束后清理该记录，不更新 AAAA 或现有 DDNS。域名会出现在公开证书透明度日志中。
6. 其他 DNS 服务商可以导入包含私钥及中间证书链的 PKCS#12 文件；证书须受 iPhone 信任。手动导入不自动为其他服务商配置续期。
7. 开启服务，分别从局域网和另一条支持 IPv6 的网络访问 `https://你的域名:8443`。仅本机检测正常不能证明外网可达。

正式签发后安排每天检查，证书剩余不足 30 天时尝试续期。网络、系统调度、Token 权限和 CA 限制可能导致失败；失败保留原证书，不降级到明文。到期前请检查签发状态。

## iPhone 配对与通知

用 Safari 打开网址，选择「分享 → 添加到主屏幕」，然后从主屏幕打开。Android 生成三分钟配对码，在 iPhone 输入后，在 Android 确认允许该设备访问和发送短信。仅向自己信任的设备授权。

iOS 16.4+ 的主屏幕网页应用可以申请通知权限。设置中订阅并测试通知；“提交成功”不等于手机收到，需要在设备端确认。在“设置 → 通知”打开“显示短信预览（本设备）”，可在通知中查看发件人和正文摘要；升级前的订阅默认保持普通提醒。

发送时确认 SIM 和收件人。结果不明时先核对实际收件情况；应用保留原请求 ID，不会自动创建新请求重复发送。网络恢复后刷新状态即可。

## 间隔检测

默认 5 分钟，可设为 1–1440 分钟，支持立即检查。检测 HTTPS、证书、默认短信角色、权限、电池优化豁免、手机全球单播 IPv6 与域名 AAAA。DNS 不一致只提示，不代替用户修改 DDNS。

免 Root 时，服务存活期间按所设间隔检测；WorkManager 补检最短 15 分钟且可能延迟。连续两次 HTTPS 失败才有限恢复，证书无效则提示处理。不能突破系统强行停止。

可选 Root 守护需要 Android 8+，在配置页启用并授予超级用户权限。独立进程每 10 秒检查应用进程，按所设间隔检查 HTTPS；连续失败才恢复，每小时最多尝试 3 次且至少间隔一分钟。不会重发短信或擅自修改默认短信角色、短信权限。

- 手动关闭公网服务或自动检测后，守护不会拉起它。
- 关闭 Root 守护会停止自己的独立进程，移除自己的开机入口；短信服务保持原状态。
- 开机后等待启动完成及首次解锁；需要兼容的 `service.d` Root 环境，当前仅在 Magisk 设备上验证过运行。
- 文件位于 `/data/adb/sms-bridge`，开机入口是 `/data/adb/service.d/98-sms-bridge.sh`。不修改其他助手。
- 启动前核对确认过的 APK 哈希。更新 APK 后点「启用 / 更新 Root 守护」，再刷新确认独立进程正常。

Root 被撤销、守护本身被杀、系统限制、网络中断仍可能使功能失效。不要把检测正常当成短信、通知或公网连接的送达保证。

## 更新、卸载与排障

使用相同签名覆盖升级，不清除应用数据。卸载前先关闭 Root 守护，再根据需要把默认短信应用切换回其他客户端。重装后需要重新签发或导入证书、重新配对。

遇到故障先查看配置检查页面和 Root 状态，再检查手机网络、域名解析、证书和路由器规则。发布问题时只提供脱敏的错误信息，勿上传短信、联系人、真实号码、配对码或密钥。
