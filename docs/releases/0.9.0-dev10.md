# CommLink 0.9.0-dev10 · 导入 iPhone 联系人

互联电话「联系人」增加导入入口。iPhone 从系统通讯录导出 .vcf、存储到文件后，可直接在网页选择，先本地预览，再明确确认导入。仅保存姓名和电话号码到助手，不写入 iPhone/Android 系统通讯录，不创建来源写回任务。导入不是持续同步；重新导出不会自动覆盖旧备注或删除旧名片。

支持常见 vCard 2.1/3.0/4.0、Apple 分组号码、折行、多个号码、UTF-16/UTF-8 和 quoted-printable。文件上限 10 MiB / 5000 张卡片。重复姓名及号码集合会跳过，同号码不同姓名保留供核对。忽略照片、邮箱、地址及备注字段。

POST /api/v2/contacts/import 需安装级 contacts.read + contacts.write。按批次事务导入，网络中断后继续使用同一 UUID 重试，收据防止重复创建；暂停只阻止后续批次。目录库 v2 → v3 仅新增 contact_imports，不修改短信库、来源或通话记录。Android 安装授权的编辑权限文案更新为「编辑助手联系人及指定来源」；本机「允许指定来源写回」仍独立控制。

验证：52 项 TypeScript、145 项 JVM、15 项安卓隔离测试通过，含实际 HTTPS 安装/只读权限拒绝导入、原子提交、重复收据、数据改变/跨安装拒绝、去重、权限隔离和 v1/v2 迁移。模拟浏览器验证预览不提交、用户确认后才导入、丢失回复后使用同一请求重试，原电话编辑、SIM、Groundwire、角标和滑动返回流程通过。

已相同签名覆盖升级连接的红米至 versionCode 33。双 HTTPS 页面/资源与 APK 一致，未授权 API 401；目录 v3，原 81 条通话、6 条查看回执逐行保留，来源写回任务仍为 0，本机系统写回未开启。升级前目录快照保存在设备 Root 私有目录并验证完整性，不代表完整应用回滚备份。Root 守护 APK 哈希与新 APK 一致，临时测试应用已卸载。真实 iPhone 文件导入仍等待用户验收；不在聊天或测试日志中收集真实联系人。

## English

Phone gains an iPhone .vcf import entry. Export names and phone numbers from Apple's Contacts app, Save to Files, then select and review the file in Phone. Explicit confirmation saves assistant-only cards; neither system address book is changed and no Android writeback is queued. This is not continuous synchronization.

Common vCard 2.1/3.0/4.0, Apple grouped numbers, folding, multiple numbers, UTF-8/UTF-16 and quoted-printable are supported, with a 10 MiB / 5000-card limit. Identical names and number sets are skipped; differing names sharing a number are kept for review. Other fields are ignored.

The import API requires both contact capabilities. Batches are atomic and retain UUIDs across retries; saved receipts prevent duplicate creation. Schema v3 adds only contact_imports, preserving call_seen and existing data. Android system writeback remains separately opt-in.

52 TypeScript, 145 JVM and 15 isolated Android tests pass, including real HTTPS capability rejection, receipts, authorization boundaries and database migrations. Browser fixtures verify explicit confirmation, retry identity and the existing Phone flows without external calls. Signed versionCode 33 is installed; both HTTPS origins match the build, 81 calls and 6 viewing receipts remain, and no writeback job is queued. Real iPhone import acceptance is pending. Temporary test apps were removed.
