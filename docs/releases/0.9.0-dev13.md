# CommLink 0.9.0-dev13 · 直接使用安卓通讯录

按用户选择，网页联系人改为以安卓系统通讯录为准，采用设备 + Android Contact ID 身份及系统显示姓名。移除 iPhone .vcf 导入、姓名顺序修复、助手名片合并/拆分、待核对和助手最近删除功能。相关导入代码、服务及测试已删除。旧助手名片保留在私有本地数据中，但不再展示、不参与短信/通话姓名匹配，也不自动迁移为安卓联系人。

网页支持新增安卓联系人、远程编辑姓名/号码及通话详情追加号码。明确选择保存手机，修改绑定到系统来源及版本；多个账号来源时保留其他来源，只读账号禁止编辑。网页收藏继续作为界面偏好。旧端点返回 410，不将缓存旧网页的助手保存动作解释为系统写入。启动时停用未执行的旧工作流写回任务；已完成历史回执及新的原生任务保留。

提交后以持久任务执行，原子标记与联系人数据同批写入；同一请求重试不重复创建。等待手机 done 确认后才提示写入成功；离线排队、拒绝和版本冲突均可见。编辑权限需同时满足系统权限、安卓本地共享/远程编辑开关、安装功能和设备授权。没有开启系统联系人删除的网页入口。

验证：51 项 TypeScript、145 项 JVM、21 项安卓隔离测试通过。新增覆盖原生 ID 聚合、旧助手卡片隔离、设备/来源权限、版本冲突、重复请求、旧任务退休、写后读模型、Provider 名称版本比较及原子标记重放。Provider 测试使用内存实现，未对生产通讯录添加测试数据。浏览器覆盖空/原生通讯录、新增/编辑/追加、明确设备且不切换、queued 不算保存、真实任务确认入口、失败提示及旧入口移除；短信、Groundwire、键盘、底部布局、角标、PWA 范围和通知回归通过。模拟流程不发真实短信/电话。

已覆盖安装红米至 versionCode 36，双 HTTPS 资源与打包文件一致，未授权 API 返回 401。目录库保持 v3，旧记录保留；通讯录共享、远程编辑及系统联系人读写权限已启用。用户确认安卓暂时没有联系人、之后自行在系统中导入，并确认 iPhone 网页显示为空且旧入口已消失。真实用户通讯录的后续编辑由用户导入后按需使用，本次验收未创建或修改真实联系人。

## English

Android system contacts now define the public address book, using device + aggregate Contact ID and Android display names. iPhone vCard import, name repair, assistant-card merge/split/review and Recently Deleted are removed. Legacy assistant-only cards remain private local archives, excluded from directory/name matching and never automatically copied into Android.

Create/edit/append explicitly selects a phone and binds the source/version. Writes use durable jobs, atomic Provider markers and idempotent requests. Queued is not saved: the UI waits for a done acknowledgement and exposes offline, denial and conflict states. System permissions, local sharing/editing consent, installation capabilities and device grants all apply. Read-only accounts are protected; other sources are preserved. Favorites remain a web preference; no system-contact delete UI is exposed.

Legacy writes return 410 to protect cached clients. Startup retires unexecuted legacy jobs while preserving completed receipts and new native operations. The schema remains v3.

51 TypeScript, 145 JVM and 21 isolated Android tests pass, alongside browser regressions. Provider tests use an in-memory seam, never a production address book. Signed versionCode 36 is installed; HTTPS assets and permissions are verified. The user confirmed an empty Android address book, plans to import into Android later, and confirmed the empty iPhone web list and removed legacy entry points. No real contact write was performed for acceptance.
