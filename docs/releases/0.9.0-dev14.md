# CommLink 0.9.0-dev14 · 修复安卓有联系人但网页为空

现场确认：系统 Contacts / RawContacts 存在有效记录，系统权限及共享授权正常；Data 查询却返回 Invalid column is_read_only。旧扫描整批失败，异常被忽略，使网页误显示为空。

仅在异常明确指向这个投影字段时，改为查询其余字段，并缓存当前 Provider 的字段能力。其他查询异常仍作为失败处理，不提交残缺快照、不删除原数据。同步扫描、姓名编辑和号码编辑均走兼容查询。保留原始账号只读、来源版本、账号绑定、当前授权和逐条影响行数校验；不添加同步适配器身份，不放宽系统写入权限。整个来源删除在无法核实字段状态时拒绝。Provider 拒绝只读字段会使批处理失败，不报告保存成功。

同步异常改为记录固定、无姓名/号码/原异常文本的提示；安卓授权页可查看，授权本机的网页列表响应可附 syncError。读取失败时网页显示提示，不再同时显示“系统通讯录暂无联系人”；成功后清除。数据库仍为 v3。

验证：51 项 TypeScript、145 项 JVM、25 项安卓检查通过，其中 24 项隔离检查和 1 项经显式开关启用的真实系统通讯录只读检查。新增覆盖不支持该投影、保留原账号与字段只读保护、系统批处理拒绝、无关异常继续失败，以及错误不会表现为空列表。真实读取检查只计数，不写入、记录或导出姓名号码。

已签名覆盖升级红米至 versionCode 37，双 HTTPS 页面/资源及 Root 守护哈希与发布 APK 一致。生产同步缓存现已出现有效安卓来源，扫描错误为空。旧名片姓名/号码、原通话身份及未接查看回执保留；未修改系统联系人内容。iPhone 网页显示结果等待用户确认。

## English

A real device contained Android contacts with valid permissions, but its Data provider rejected the is_read_only projection. The full scan aborted and the previous code hid the error.

Retry without that column only for an explicit matching exception. Retain raw-account guards, source/account revisions, current authorization, ordinary caller privileges and exact affected-row constraints. Do not bypass read-only fields by impersonating a sync adapter. Unsupported whole-source deletion fails closed; other failures remain failures and cannot commit partial snapshots.

Persist only sanitized scan errors and surface them through the authorization screen and scoped syncError response. Do not represent failed reads as an empty address book. Successful scans clear the error. Schema stays at v3.

51 TypeScript, 145 JVM and 25 Android checks pass: 24 isolated checks plus one explicitly enabled read-only probe against the actual contacts provider. It counted records without writing or logging personal contents. Signed versionCode 37 is installed; HTTPS assets and the watchdog hash match. Production source sync is now non-empty and scan errors have cleared, with existing data retained. iPhone display acceptance is pending.

Reference: [Android Data.IS_READ_ONLY](https://developer.android.com/reference/android/provider/ContactsContract.DataColumns#IS_READ_ONLY).
