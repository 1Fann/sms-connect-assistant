# CommLink 0.9.0-dev15 · 联系人页面

互联电话的联系人列表、详情、新建和编辑页面按提供的 iPhone 电话录屏调整。列表采用圆形顶栏按钮和头像、姓名列分隔线与可拖动的字母索引，索引定位已载入的分组。已有权限范围内的小尺寸安卓 JPEG/PNG 缩略图可用时，页面显示联系人头像。

详情采用蓝灰至紫色渐变，编辑入口位于右上角。点信息或电话可以选择联系人的号码，单号码可直接进入短信草稿或拨号页。支持系统分享的浏览器也可共享姓名和号码。

编辑和新建采用分组字段、取消与完成按钮，号码可逐行添加和移除。编辑页保留底栏，新建使用底部弹层。保存沿用安卓联系人来源、版本和写入回执。

已通过 51 项前端测试、4 套浏览器模拟流程和 10 项安卓隔离检查。已安装 versionCode 38，并核对手机实际提供的两套 HTTPS 页面及资源。界面截图使用合成联系人数据。

## English

The Phone directory, contact details, new-contact sheet and editor follow the supplied iPhone recording. The list has circular controls, inset separators and a draggable index for loaded sections. Authorized Android thumbnails are displayed when a suitable JPEG or PNG is available.

Contact details pair a gradient poster with an upper-right Edit button. Message and Call offer number selection for contacts with several numbers. The editor groups fields into rows with add/remove controls and retains Android source binding, revision checks and write acknowledgements.

51 frontend checks, four browser fixture flows and ten isolated Android checks passed. Signed versionCode 38 was installed and both HTTPS origins served the packaged assets.
