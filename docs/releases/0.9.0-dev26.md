# CommLink 0.9.0-dev26 · 短信启动与联系人优化

这是开发预发布版本，versionCode 为 49。沿用现有应用包名与签名，可覆盖升级同签名的旧安装。APK 包含 Android 代码、「互联信息」和「互联电话」的网页资源，不需要另行部署网页。

## 本版及累计调整

- 已缓存的短信界面立即显示，后台检查页面更新。先准备新页面引用的脚本、共享模块和样式，再更新缓存页面；下载中断时保留完整旧版。
- 同版本资源复用本地缓存。首次会话检查、短信和会话状态并行读取，避免重复初始查询。
- 安卓短信查询在一页内复用无联系人匹配结果、号码格式和 SIM 信息；通讯录姓名按一页批量解析，减少服务短号反复扫描通讯录。匹配仍受授权设备、通讯录共享和重名规则约束。
- 累计包含 dev16–dev24 中保留的联系人多号码原生顺序、优先处理网页写回、系统电话键盘、点空白收起及键盘布局调整。临时键盘诊断页面不包含在交付版本中。
- 保留双 PWA、独立配对、通话记录和未接角标、安卓通讯录远程编辑，以及 Groundwire 从拨号开始承载原生语音。网页已移除麦克风采集、WebRTC 通话和后台转接流程。

## 升级与限制

先打开主屏幕「互联信息」停留几秒，再从多任务关闭并重新打开，让新 Service Worker 激活。首次加载仍需要下载界面；后续短信内容和登录验证仍需网络。不会持久缓存短信正文、认证 API 响应或凭据。

联系人编辑时的系统键盘在部分 iPhone 上仍可能引起短暂页面闪动，本版不宣称完全解决。姓名键盘上的输入工具栏由 iOS 管理。

首次安装仍需授予权限、配置证书与域名并完成配对。APK 不包含个人证书、Token、配对数据、签名私钥或独立 PBX 配置；签名覆盖升级保留应用私有配置，卸载会清除它们。可选语音仍需要 Voice SIP Agent、Asterisk 和 Groundwire。

## 验证

- 145 项 Android JVM 测试、51 项前端测试及 18 项安卓隔离通讯录测试通过；隔离测试仅使用合成数据，没有修改真实通讯录或发送短信。
- 浏览器覆盖配对、幂等重试、发送状态、会话状态顺序、双 PWA、通知预览和跨页短信草稿。
- 实际浏览器的 Service Worker 测试确认：即使页面网络请求挂起，缓存界面仍能打开，且无需重新下载版本资源。测试也覆盖更新中断和 API 缓存排除。桌面测试不等同于 iPhone 实测耗时。
- 已将相同 APK 安装到测试 Redmi，核对两个 HTTPS 入口、打包资源、默认短信角色及联系人写入权限。没有在本轮自动发起真实短信或通话。

## English

This is a development prerelease, versionCode 49. The APK retains the existing application ID and signing identity and bundles Android code and both PWAs. No separate web deployment is needed.

The Messages shell renders from cache while a complete update is prepared in the background. New entry scripts, shared modules and styles are cached before publishing new HTML. Interrupted updates retain the previous complete shell. Initial reads run in parallel; sender names, formatting and SIM lookups reuse request-local results, and directory name matching is batched without bypassing device authorization or ambiguity checks.

This release also includes the retained contact number ordering, prioritized Android write-back and system keyboard refinements from dev16–dev24. Temporary keyboard diagnostics are excluded. Both PWAs, pairing, call records, missed-call badges, Android contact editing and Groundwire-native calling remain available. Browser microphone capture, WebRTC calling and background voice handoff are removed.

Open Messages once, wait briefly, close it from the app switcher and reopen it to activate the new Service Worker. First use still downloads the shell; authentication and SMS content still require network access. Authenticated APIs, SMS bodies and credentials are not persisted in the shell cache. Some iPhones may still briefly shift or flash when the contact editor keyboard changes; that issue is not claimed as fully resolved. The name-input accessory bar is controlled by iOS.

Fresh installations still require permissions, a trusted certificate, domain configuration and pairing. Personal certificates, tokens, pairings, signing keys and external PBX configuration are not bundled. Optional voice requires Voice SIP Agent, Asterisk and Groundwire.

Validation passed 145 JVM tests, 51 frontend tests, 18 isolated Android directory checks and the relevant browser fixtures. A real browser confirmed cached startup with the shell network deliberately blocked, complete-update behavior and API cache exclusion. These desktop results are not iPhone timing claims. The same APK was installed on a Redmi and both HTTPS entry points, packaged assets and existing permissions were checked. No real SMS or calls were initiated automatically during these checks.
