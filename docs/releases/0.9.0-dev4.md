# 0.9.0-dev4 · 互联电话界面 / Phone interface

按用户提供的两段 iPhone「电话」录屏调整网页界面。参考视频及提取帧只用于本地观察，不包含在发布源码或 APK 中。

- 三项悬浮底栏「通话、联系人、拨号键盘」，独立搜索按钮。互联设置移至通话筛选菜单和拨号页右上角。
- 通话头像、未接颜色、相对日期、来源标识、过滤菜单与编辑选择。左滑只从当前安装的助手列表移除，可在最近移除中恢复；安卓原始记录保留。PBX 与系统记录保留独立身份，不猜测合并。
- 紫色联系人海报、详情滑入及返回拖动；头像只使用已有姓名或默认图形，不虚构联系人照片。
- 通讯录分组、离线拼音/字母索引及原有授权读写、来源核对功能。搜索通话仅覆盖已载入记录；可继续分页。
- 透明质感圆形拨号键、长按 0 输入 +、退格长按连删、独立 SIM 选择。SIM 不可用时禁止拨出，不自动切换线路。
- 通话中的静音、DTMF、保持、声音播放与 Groundwire 接续使用原有流程；诊断信息折叠显示，音频测试仍在设置中。
- 保留浅/深色、小屏适配、键盘避让及减少动态效果偏好。网页没有加入不受支持的视频、录音或语音信箱按钮。

验证：40 项前端测试、152 项 Android JVM 测试、签名 APK 构建通过。浏览器合成数据测试覆盖筛选、搜索、详情、左滑恢复、跨安装隔离、拨号输入和长按、小屏拨号键不被遮挡；测试未连接 SIP 或发起真实电话。短信的两设备线路、未知发送核对和双 PWA 缓存/通知隔离回归通过。设备端 HTTPS 页面与资源核对通过。此版本不改变 PBX、凭据或数据库结构；本次未重新进行运营商、锁屏及接续验收。

## English

The Phone PWA now follows the supplied iPhone recordings: a three-tab floating dock and separate search control, avatar-based recents, a filter menu, reversible local removal, contact posters, indexed contacts, glass-style dial keys, hold-zero for + and hold-backspace for deletion. Existing SIM validation, voice controls, pairing, directory authorization and audio lifecycle remain in use. Unsupported native features are not represented as working controls.

Removal is per installation in this browser and preserves Android records. PBX and Android records retain distinct identities and source labels. Call search covers loaded history; paging remains available. Reference videos and extracted frames are excluded from release artifacts.

Validation passed: 40 frontend tests, 152 Android JVM tests, signed build, synthetic browser interaction tests, SMS regression and PWA isolation checks. Automated UI tests placed no calls and opened no SIP connection. Deployed HTTPS assets were checked. Carrier audio, CallKit and handoff were not re-accepted in this UI-only iteration.
