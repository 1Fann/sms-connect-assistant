# CommLink 0.9.0-dev5

Groundwire 拒接、未接听或媒体验证失败后，保留现有外线并恢复网页通话。网页连接已断开时，提供一分钟的恢复窗口与「恢复网页通话」按钮；恢复使用当前通话的短期、一次性票据，不重新呼叫蜂窝号码。网页连接尚在时，返回页面会尝试恢复声音播放；iOS 音频采集被中断时，可点按钮重新获取麦克风并接回原通话。

修复旧 SIP 会话迟到的挂断回调关闭新麦克风的问题。恢复接口校验当前安装、线路授权及存活的外线；已结束的通话、撤销授权和重复使用的票据不能重新接入。断开的网页一分钟内没有恢复，会结束保留的外线。

验证：40 项 TypeScript 测试、152 项 JVM 测试、8 项隔离安卓语音控制器测试；网页模拟验证拒接/恢复状态、恢复按钮、迟到的旧连接事件及没有重复拨号请求；原电话页面浏览器回归通过。隔离测试使用虚拟 ARI，不拨打真实电话。实际 iPhone / Groundwire 拒接后的音频恢复仍需真机验收。

## English

Groundwire rejection, timeout or failed media verification can now fall back to the existing web call. If the browser leg was interrupted, the outside leg is retained for up to one minute and the “Restore web call” action reconnects it using a short-lived, single-use ticket. Recovery never originates another cellular call. Returning to the page retries audio playback; interrupted iOS microphone capture can be reacquired through the recovery button.

Late hangup callbacks from an older SIP session no longer stop a newer microphone. Recovery checks installation ownership, current line authorization and the existing outside channel. Ended calls, revoked installations and replayed tickets cannot reconnect. Calls left without a browser connection are cleared after the recovery window.

Validation: 40 TypeScript tests, 152 JVM tests, 8 isolated Android voice-controller tests, browser recovery fixtures and the existing Phone UI regression. Controller fixtures use fake ARI and place no real calls. iPhone / Groundwire rejection and audio recovery still require real-device acceptance.
