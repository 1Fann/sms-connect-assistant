# CommLink 0.9.0-dev7 · 通话记录 SIM 标识

通话列表副标题、详情标题及每条历史记录增加设备和 SIM 卡槽显示。呼出、呼入、未接及拒接均使用该条记录保存的 slot，不从当前 SIM 排序、Groundwire 出站账号或默认卡推断。原网页通话档案的只读接口补充其已保存的 slot；缺失或无效时显示「SIM 未知」。

当前红米已同步的历史记录具备明确卡槽，无需重新拨号或修改原始安卓记录即可显示。Groundwire 原生拨号、短信和记录共享流程保持原实现。

验证：43 项 TypeScript 与 145 项 JVM 测试通过，签名 release 构建完成；浏览器覆盖 SIM 1、SIM 2、未知卡槽的列表和详情，以及 Groundwire 拨号入口和原页面交互。使用合成数据截图核对显示；没有自动拨打电话或读取短信正文。已原签名覆盖安装到主节点（versionCode 30），双 HTTPS 页面与打包资源一致，原通话记录共享开关保持开启。

## English

Call list subtitles, detail headers and individual history entries now display the source device and recorded SIM slot for outgoing, incoming, missed and rejected calls. The display uses the stored slot, never the current line ordering, Groundwire account or default SIM. The read-only browser-call archive also returns its stored slot. Missing or invalid values remain “SIM unknown”.

Existing synchronized records on the deployed Redmi already contain slot metadata, so no new calls or modifications to Android call records are needed. Native Groundwire dialing and SMS remain unchanged.

Validation: 43 TypeScript tests, 145 JVM tests, the signed release build and browser checks for both SIMs, unknown slots, history details, native dial links and existing Phone interactions. Synthetic screenshots were inspected. No automated calls were placed and no SMS bodies were read. Signed versionCode 30 was installed on the host; both HTTPS apps match the packaged assets and call-log sharing remains enabled.
