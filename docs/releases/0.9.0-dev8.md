# CommLink 0.9.0-dev8 · 拨号首页与底部布局

互联电话普通打开时默认进入拨号键盘。未接来电通知的 `#missed` 入口仍进入未接记录。

底部三项导航和搜索下移约 8–12 像素；数字键及拨号按钮按可用高度下移约 12–20 像素，压缩提示文字下方留白。布局同时计算顶部与底部安全区，小屏幕保持拨号按钮可见，不用额外滚动拨号页。

验证：TypeScript 检查和双入口构建通过；浏览器验证默认首页、通知入口、底部间距、小屏幕与 59/34 像素安全区、无额外滚动、拨号按钮无遮挡，以及既有记录/SIM 显示、联系人和 Groundwire 链接。截图已核对。签名 release 构建通过并已覆盖安装到主节点（versionCode 31），双 HTTPS 的页面与静态资源已核对一致。本轮没有拨打电话。

## English

Phone now opens to the keypad by default. The `#missed` notification link still opens missed calls.

The navigation and search dock moves down by approximately 8–12 CSS pixels. Number keys and the call button move down by approximately 12–20 pixels depending on available height, with less unused footer space. Top/bottom safe areas and compact screens remain supported without extra keypad scrolling or a covered call button.

Validation: TypeScript and both web builds; browser checks for the launch page, notification link, dock clearance, compact and simulated 59/34-pixel safe areas, scrolling, call-button visibility, history/SIM labels, contacts and native Groundwire links. Screenshots were reviewed. The signed release was installed on the host as versionCode 31, and both HTTPS pages/assets match the build. No calls were placed.
