# CommLink 0.9.0-dev9 · 短信入口、轻扫返回与未接角标

通话详情的圆形操作改为左侧短信、右侧电话，移除重复的圆形通话记录入口，保留下方「通话记录」按钮。短信入口打开同域名 8443 的互联信息网页，并通过 URL fragment 预填收件人；fragment 读取后从地址栏清除，不传输凭据、不自动发送。未配对的浏览器会话先完成独立短信配对，配对后继续进入原预填草稿。

详情不再限定从左侧窄边缘起滑。横向滑动约 44 像素，或较快的约 18 像素短扫，即可返回；竖向滚动和左滑不会触发返回，拖动期间避免误触短信/电话按钮。

未接来电按电话安装及来源设备记录查看状态，主屏幕角标与底部通话标签显示未查看数量。查看当前列表中的未接记录后清除对应数量，不更改安卓系统通话记录。后台 Push 先显示通知和提示角标，再读取最新计数；支持访问会话续期、离线保留提示、撤权后清除。iOS 显示角标需要已添加到主屏幕并允许该网页应用的通知及角标。

目录数据库从 v1 增量升级到 v2，仅增加独立 call_seen 表，以安装、设备、原始 ID 和记录日期区分查看状态。旧记录保留，原始 ID 复用不会误标新来电。升级前目录快照保存在设备 Root 私有目录并完成完整性检查；不要直接降级旧目录数据库版本的 APK。

验证：47 项 TypeScript、145 项 JVM、10 项安卓隔离测试、9 项短信提交日志与 3 项目录 SQL 测试通过；浏览器覆盖短信预填（已配对/待配对）、零自动发送、左右按钮顺序、短扫返回、角标查看回执、原短信发送状态与原电话页面；Worker fixture 覆盖计数、清除、离线、续期与撤权。已安装 versionCode 32；双 HTTPS 资源与构建一致；目录库 v2，原 81 条记录无丢失。用户已确认 iPhone 主屏幕红色角标显示，并完成短信浏览器会话的首次配对。iOS 的跨范围网页应用链接会进入 Safari 视图，不能保证直接唤起另一个已经安装的主屏幕 PWA；后续无 Safari 体验应改为电话内编辑短信。

参考：[WebKit 主屏幕角标](https://webkit.org/blog/14112/badging-for-home-screen-web-apps/)。

## English

Call detail actions are now Message on the left and Call on the right, retaining only the lower history button. Message opens the Messages origin on port 8443 with a recipient fragment, removes that fragment after reading, never transfers credentials and never sends automatically. An unpaired browser session completes its own SMS pairing before resuming the prefilled draft.

Detail back gestures work across the sheet, using a roughly 44px drag or a quick 18px swipe. Vertical scrolling and leftward movement do not dismiss it; completed drags suppress accidental action clicks.

Missed-call viewing receipts are scoped to each Phone installation and source device. Home Screen and navigation badges show unviewed counts and clear viewed entries without modifying Android call logs. Background pushes show a notification/dot before refreshing the count, renew expired sessions, retain an offline dot and clear revoked access. iOS requires a Home Screen installation with notification/badging permission.

Directory schema v2 adds only call_seen, keyed by installation, device, provider ID and date. Existing data is retained, including when a provider reuses an ID. A private pre-upgrade snapshot was integrity-checked. Do not downgrade to an older directory-schema APK.

Validation: 47 TypeScript, 145 JVM, 10 isolated Android, 9 SMS journal and 3 directory SQL tests; browser compose/pairing/zero-send, action order, short swipe, badge receipts and existing UI regression; Worker count/clear/offline/refresh/revocation fixtures. Installed versionCode 32; live HTTPS assets match the build; schema v2 retains all 81 earlier call records. The user confirmed the iPhone Home Screen badge and completed the separate browser SMS pairing. On iOS, out-of-scope links open a Safari view; they cannot reliably activate another installed Home Screen PWA. An in-Phone composer is the proposed alternative for avoiding Safari.
