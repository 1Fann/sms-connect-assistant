# CommLink 通讯互联 0.9.1

版本名改为 **0.9.1**，内部 versionCode 为 **53**。本版汇总 0.9.0-dev27 至 dev29 的修复，继续沿用应用包名和签名，可覆盖升级同签名的旧版本。

## 更新内容

- 区分验证中、已授权和未配对状态，避免启动时先闪出配对页。
- 首次鉴权、实时短信和当前授权范围的会话状态合并返回，数据准备好后直接进入列表，去掉中间一帧“正在载入”。
- 批量读取一页短信的 SIM 线路映射，并复用同页已读时间查询。保留历史线路绑定、已读、置顶、静音及移除规则。
- 网络失败提供重试，确认授权失效才显示配对。首次同步旧服务端仍支持独立会话状态接口。
- 不增加 iPhone 短信缓存；每次读取安卓实时数据。已有缓存仅用于网页界面资源，实际等待仍受网络往返影响。

## 安装与范围

APK 包含 Android 代码和「互联信息」「互联电话」两套网页。覆盖升级保留应用私有配置，首次安装仍需授权、可信证书、域名和配对。可选语音依赖独立配置的 Voice SIP Agent、Asterisk 和 Groundwire。

覆盖升级后先打开主屏幕「互联信息」停留几秒，再从多任务关闭并重开，让新版网页生效。

联系人编辑键盘在部分 iPhone 上可能仍有短暂闪动；本版不宣称已完全解决。网页外观和手势也不等同于 iOS 原生控件。历史开发版本和已有配置继续兼容。

## English

The version is now **0.9.1**, with Android **versionCode 53**. This release includes the fixes from dev27–dev29 and retains the package ID and signing identity for in-place upgrades.

Startup distinguishes pending, authenticated and unpaired states. One authenticated live response supplies SMS and scoped conversation metadata. The inbox data is published together before leaving the startup screen, preventing the pairing-page flash and the second loading frame. SIM aliases are read per page, and read timestamps are reused within a request, while preserving historical line bindings and conversation behavior.

Network failures offer retry; authentication rejection opens pairing. Older hosts retain the separate metadata fallback. No persistent iPhone SMS cache is introduced; only interface resources are cached, and network latency still limits live startup speed.

The APK bundles Android code and both PWAs. Signed upgrades preserve private configuration. Fresh installations require permissions, a trusted certificate, domain setup and pairing. Optional native calling requires separately configured Voice SIP Agent, Asterisk and Groundwire.

Open Messages briefly, close it from the app switcher and reopen it after upgrading to activate the updated web assets. Contact-editor keyboard transitions may still briefly shift on some iPhones; that issue is not claimed as fully resolved. Web controls are not native iOS controls.
