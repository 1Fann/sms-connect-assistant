# 通讯互联 CommLink 0.9.15

## 中文

- 互联信息在加载界面脚本时同步请求短信，先显示实时会话，再补齐联系人姓名。
- 互联电话用一次请求载入登录状态、设备和线路。已添加到主屏幕的网页可立即读取现有界面资源，返回前台会立即刷新线路。
- 压缩电话与短信网页的脚本和样式。两个应用仅缓存界面资源，短信、通话记录及线路状态仍实时读取。
- Root 守护识别 Android 拒绝启动服务的结果，遇到冷启动失败时可通过受系统权限保护的入口尝试恢复共享服务。

- 同一 SIM 回到原卡槽后保留确认。可在主安卓为指定卡槽开启自动接管，换入新 SIM 时保留线路名称、排序和默认设置，已排队短信仍绑定原订阅。

## English

- Messages requests live history while the interface scripts load and fills in contact names after the first render.
- Phone loads the session, devices, and lines in one request. Its installed web app can reuse interface assets and refreshes live line state on return to the foreground.
- Compresses scripts and styles. Cached assets contain interface resources only; messages, call records, and line state are fetched live.
- The root watchdog detects rejected Android service launches and can retry a failed cold start through a system-permission-protected entry point.

- Keeps confirmation when the same SIM reappears in its original slot. Optional per-slot takeover carries over the line name, order, and default selection. Queued SMS stay bound to the original subscription.
