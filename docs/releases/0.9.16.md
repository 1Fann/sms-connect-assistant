# 通讯互联 CommLink 0.9.16

## 中文

- 修复 iPhone 主屏幕角标在收到后台通知后消失的问题：短信和未接来电都改用数字角标，避免 iOS 不支持的无数字标记。
- 新短信在后台先显示「1」作为未读提示，打开互联信息后校正为实际未读会话数。未接来电会进一步读取实际数量；网络暂不可用时保留「1」，不会因查询失败清掉提示。
- 测试短信预览仍不改变角标；确认已查看的未接来电仍正常清除。没有新增后台轮询、定时唤醒或短信内容缓存。
- 更新安卓后，分别打开并关闭两个主屏幕应用，让后台通知程序完成更新。首次打开期间可能仍由旧程序控制，必要时再重开一次。

## English

- Fixes iPhone Home Screen badges disappearing after background notifications. Messages and missed calls now use numeric badges instead of an unnumbered flag that iOS does not display.
- A background SMS shows “1” as an unread indicator; opening Messages reconciles the actual unread conversation count. Phone fetches the missed-call count and keeps “1” if that request fails.
- Preview tests leave the badge unchanged, and confirmed viewed calls still clear it. No background polling, scheduled wake-ups, or message-content cache was added.
- After updating Android, open and close both Home Screen apps to update their notification workers. If the previous worker is still active on the first launch, reopen once more.
