# 0.9.20

## 中文

- 修复收到新短信后，主屏幕角标从实际未读数变成 1 的问题。后台现在查询完整的未读会话数，打开应用前后使用相同统计口径。
- 修复电话推送先把角标改成 1 的问题。只有查询成功后才更新未接来电数；断网、登录失效或返回异常时保留原数字。
- 短信统计遵守已授权设备范围、已读标记、手动标为未读及移除会话状态；不受首页短信分页限制，不缓存短信正文。

升级后请分别打开「互联信息」和「互联电话」，等待片刻，关闭后再打开一次，以加载新版后台脚本。实际角标显示仍需在 iPhone 上验证。

验证：短信计数单元测试、短信和电话推送模拟测试、会话及电话角标回归测试、TypeScript 检查、正式 APK 构建通过。主设备已原位升级，两个网页实际提供的后台脚本与构建内容一致。

## English

- Fixed SMS notifications replacing the Home Screen unread badge with a hard-coded 1. Background and foreground updates now query the same complete unread-conversation count.
- Removed the temporary 1 from missed-call push handling. Badges change only after a successful count query; network, authentication and invalid-response failures preserve the existing value.
- SMS counting respects authorized devices, read markers, manually unread conversations and removed history, without the inbox page limit or caching message bodies.

After upgrading, open both Home Screen apps, wait briefly, close them and reopen once to load the updated service workers. On-device iPhone badge behavior still requires verification.

Validation passed: Android count tests, SMS and phone push simulations, conversation and missed-badge regressions, TypeScript checks and the signed release build. The primary Android device was upgraded in place, and both served workers match the build.
