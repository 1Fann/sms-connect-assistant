# 0.9.21

## 中文

这次主要修复 iPhone 主屏幕角标：收到新短信或未接来电时，数字不再被错误改成 1，并减少长时间未打开网页后角标无法更新的情况。

- 短信和电话推送直接携带实际未读／未接数量，无需收到通知后再连接家中安卓查询。
- 支持苹果声明式推送。在支持的系统上，通知和角标可直接由系统处理；旧系统保留兼容方式。
- 关闭短信预览时，仅推送通用提醒和数量；测试通知不改变角标。
- 保留已有配对和通知设置，不自动开启已关闭的通知或短信预览。

升级后，请分别打开主屏幕的「互联信息」和「互联电话」，停留约 10 秒，再关闭并重新打开一次，让旧订阅完成升级。

推送仍需要网络送达；延迟送达可能暂时显示发送时的旧数量，打开应用会重新核对。没有增加定时保活通知，也不能保证所有 iOS 状态下角标永久显示。长期待机效果仍需实机观察。

验证通过：60 项前端测试、短信与电话后台推送模拟、14 项 Android 单元测试、2 项实机隔离数据库升级测试，以及正式签名 APK 构建。

## English

This release fixes iPhone Home Screen badge counts unexpectedly changing to 1 and improves updates after the web apps have not been opened for some time.

- SMS and missed-call pushes include their actual counts, removing the required connection back to the Android gateway when a notification arrives.
- Added Apple Declarative Web Push. Supported systems can display notifications and badges directly; older systems retain compatible handling.
- With SMS previews disabled, pushes contain only generic notification text and the count. Test notifications do not change badges.
- Existing pairing and notification preferences are preserved. Disabled notifications and previews stay disabled.

After upgrading, open both Home Screen apps, wait about ten seconds, close them and reopen once to upgrade existing subscriptions.

Network delivery is still required. Delayed pushes may temporarily show their send-time counts, reconciled when the app opens. No periodic keepalive notifications were added, and persistent badge display in every iOS state is not guaranteed. Long-idle behavior still needs device observation.

Validation passed: 60 frontend tests, SMS and phone worker push simulations, 14 Android unit tests, two isolated on-device database-migration tests and the production-signed APK build.
