# CommLink 通讯互联 0.9.3

## 中文

版本号 0.9.3，versionCode 55。修复 iPhone 短信设置页把同一卡槽的当前 SIM 与旧线路都显示为“SIM 2”、难以区分的问题。

- 在位 SIM 显示在主列表，并标注“当前卡”，同时显示待确认、已停用、手机离线或暂不可用的状态。
- 已不在位的线路收进默认折叠的“历史线路”，仍可改名，保留原有短信关联和线路标识。
- 两处短信发送线路菜单补充历史线路和不可用状态提示。历史、待确认及停用线路不能用于发送，原有默认线路和草稿不会自动切换到另一张卡。

同包名、同签名覆盖升级，保留配对、名称、历史短信及 SIM 确认状态。历史记录不会被删除或自动合并，新卡仍需在安卓端核实后确认。网页随 APK 更新，iPhone 关闭页面后重新打开可加载新界面。

验证包括手机尺寸下的浏览器回归，覆盖同卡槽新旧两条线路、历史默认折叠、历史改名、待确认提示、发送选项禁用及原有改名和刷新流程。构建检查不发送真实短信。

## English

Version 0.9.3, versionCode 55, fixes indistinguishable current and historical SIM entries for the same slot in the iPhone Messages settings.

- Present SIMs remain in the main list with current-card, confirmation, disabled, phone-offline or unavailable status.
- Absent lines move into a collapsed history section. Their names remain editable and their stable identities and SMS associations remain intact.
- Both SMS line selectors explain historical and unavailable states. Historical, unconfirmed and disabled lines remain unavailable for sending. Existing defaults and drafts do not silently switch SIMs.

An in-place update retains the package ID, signing identity, pairing, names, message history and confirmation choices. Old records are retained without automatic merging. A replacement SIM still requires explicit verification on Android. Reopen the iPhone web app after updating the APK to load the new UI.

Validation covers a mobile-size browser fixture with two identities on one slot, collapsed history, historical renaming, confirmation labels, disabled send options and existing alias editing and reload flows. Build checks do not send actual SMS.
