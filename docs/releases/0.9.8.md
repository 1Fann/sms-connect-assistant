# 0.9.8 · 来电线路名称 / Incoming line names

## 中文

通讯互联按已有的稳定设备、线路、卡槽和订阅绑定，导出短信设置中的手机名和卡名。导出不包含短信、通讯录、凭据或号码字段，仅用于本机 PBX 显示；用户自行放在名称中的内容仍属于该名称。换卡未确认、线路不匹配时不沿用旧别名。改名时同步更新导出。

本部署的 Root 同步脚本每两秒检查一次名字导出，将其原子复制到 PBX 可读取的位置，并通过 service.d 随开机启动。普通短信收发不需要此脚本；只有本机来电名称显示集成使用它。安装模板见 `ops/asterisk/sync-incoming-line-names.sh`，来电 AGI 见 `ops/asterisk/incoming-line-label.py`。部署者需自行将脚本安装到受控 Root 路径；单独安装 APK 不会自动修改 PBX。

配套独立网关 0.3.5-custom.7 通过来电实际 Telecom 账户解析 SIM 卡槽，并在蜂窝转 SIP 时发送 `X-VSA-SIM`。PBX 根据认证端点确定设备；本部署 2001 对应 *81*/*82*，2002 对应 *83*/*84*。AGI 在原有号码分段之后，仅修改显示名称，原始号码和隐私标记保持不变；号码受限制时不查询或加入姓名、号码。未知 SIM 或重复卡槽头不猜测卡槽。未安装名称同步时回退“主设备/从设备 · SIM 卡槽”。

Groundwire/CallKit 的本地联系人匹配可能覆盖 SIP 显示名称，需按实际 iPhone 验收。该方式不创建系统原生双卡标签，仍只使用客户端 1001。

验证：通讯互联 152 项发布单元测试、AGI 7 项测试通过；网关 telephony 50、pjsua2 20、app 96 项测试通过。两台安卓均覆盖安装相同签名网关。用户已确认设备/卡槽标记正确，并确认 iPhone 来电中的自定义名称与短信设置一致。

## English

CommLink exports only the configured phone/SIM display names for exact stable route bindings. Renames update the export; mismatched or unconfirmed SIM replacements do not inherit aliases. The optional root script copies this small file atomically to the local PBX every two seconds and starts at boot. The APK does not silently install or reconfigure a PBX; deploy the provided sync and AGI scripts explicitly.

The separate Voice SIP Gateway 0.3.5-custom.7 resolves incoming SIM slots through the actual Telecom account and forwards `X-VSA-SIM`. The PBX identifies the authenticated gateway and decorates the display name using the configured aliases. Caller number and presentation flags remain unchanged. Restricted identities are not queried or appended. Unknown or duplicate slot information is not guessed. Groundwire/CallKit contact matching may override server names; physical iPhone acceptance is required.

Validation: 152 CommLink release tests and 7 AGI tests passed; gateway telephony 50, pjsua2 20 and app 96 tests passed. Both gateways were upgraded with their existing signing identity. The user confirmed both the device/slot labels and the final custom-name display on iPhone.
