# 通讯互联 CommLink 0.9.9

## 中文

改善 iPhone 主屏幕「互联信息」「互联电话」的未读角标恢复，避免暂时无法查询状态时把未读当成零。

- 电话后台登录刷新失败、限流或服务暂不可用时保留红点；成功取得零条未查看来电后才清除。
- 电话启动时尚未取得登录状态，不再提前清空图标角标；明确退出仍会清除。
- 两个应用回到前台时重新校准角标；挂起页面不会用旧的零条记录覆盖新推送。
- 短信通知展示和角标更新分别等待，单项失败不会提前结束整个推送处理。

更新：覆盖安装 APK 后，从多任务关闭两个主屏幕网页应用并重新打开。若旧页面尚未更新，再关闭重开一次；无需重新配对或重新添加图标。

验证：57 项网页单元测试、电话推送故障场景、短信预览与通知路由、两应用缓存隔离及 APK 构建通过；两台安卓已原位升级，实际 HTTPS 路径已返回新 Service Worker。长期闲置仍需持续观察；iOS 自行清除角标的行为无法由网页完全阻止。

## English

Improves unread badge recovery for the installed Messages and Phone web apps. Temporary authentication renewal failures, rate limits and server outages no longer clear the Phone badge. Startup without an authenticated session preserves the existing badge. Successful zero-count responses, viewing calls and explicit logout still clear it.

Both apps reconcile badges when returning to the foreground. Suspended pages cannot overwrite a newer push badge with stale zero counts. SMS notification display and badge updates are settled independently.

Install over the existing APK, close both Home Screen apps and reopen them. A second close/reopen may be needed for a waiting Service Worker update. No pairing or icon reinstallation is required. Web tests, push failure scenarios, cache isolation and APK builds passed; long-idle behavior still needs observation. The web app cannot fully prevent badge clearing initiated by iOS.
