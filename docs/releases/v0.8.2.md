## 中文

短信互联助手 0.8.2 支持两部兼容的安卓手机配对共享，并允许自定义手机和 SIM 卡名称。

- 一部作为服务器手机，另一部作为共享手机，不限品牌。iPhone 可汇总查看两部手机的短信，并选择对应手机的 SIM 卡发送。
- 在 iPhone「设置 → 手机与 SIM 名称」中分别改名。名称最多 30 个字符，清空后保存恢复默认名称；短信来源、详情及发送线路同步显示新名称，实际发送设备和卡槽不变。
- 共享手机显示在线状态，离线线路不可发送，也不会自动改用另一部手机。共享服务保持前台运行，并加入息屏时维持同步的处理。

已通过 136 项 Android 单元测试、35 项前端单元测试、Android 构建及移动尺寸浏览器流程，以及真机配对、短信同步、四条 SIM 线路在线、名称保存和恢复默认验证。此前进行了约一分钟息屏在线观察；本轮未发送真实短信，也未完成所有机型、长时间息屏和双手机重启验收。

下载下方 APK 覆盖安装可保留已有配对和配置。两部手机均可使用同一 APK；已有 0.8.1 共享客户端可继续连接 0.8.2 服务器。更新后请核对短信、SIM、自启动和后台权限，部分系统会在覆盖安装后撤回权限；iPhone 刷新页面后使用新功能。已启用 Root 守护的用户，请确认守护副本已更新。可用同页 SHA256SUMS.txt 核对安装包。双手机配置说明见仓库 docs/MULTI_PHONE.md。

## English

SMS Connect Assistant 0.8.2 pairs two compatible Android phones for SMS sharing and adds custom phone and SIM names.

- Use one server phone and one sharing phone, regardless of brand. The iPhone combines their message history and offers each phone's SIM lines for sending.
- Rename phones and SIMs separately in the iPhone settings. Names support up to 30 characters; saving an empty name restores the default. Message sources, details and sending selectors use the new names without changing the physical sending device or slot.
- Shared lines show their online state. Offline lines cannot send and never automatically fall back to the other phone. The sharing service runs in the foreground and keeps synchronization active while the screen is off.

Validation includes 136 Android unit tests, 35 frontend unit tests, an Android build, mobile-size browser flows, and live checks of pairing, SMS synchronization, four online SIM lines, name saving and default restoration. An earlier screen-off observation lasted approximately one minute. This round did not send real SMS messages and does not establish compatibility with every model, prolonged screen-off operation or a full two-phone reboot cycle.

Install the APK below over the existing app to retain pairing and configuration. Both phones use the same APK; an existing 0.8.1 sharing client remains compatible with a 0.8.2 server. Recheck SMS, SIM, autostart and background permissions after installation, as some systems revoke permissions during replacement installs. Refresh the iPhone page to load the new features. If you use the root watchdog, confirm its stored APK has been updated. Use the attached SHA256SUMS.txt to verify the download. See docs/MULTI_PHONE.md in the repository for setup instructions.
