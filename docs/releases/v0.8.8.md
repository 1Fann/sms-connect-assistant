## 中文

短信互联助手 0.8.8 更新了 iPhone 主屏幕应用的信息通知和聊天操作。

- 通知默认仍为普通提醒。每台 iPhone 可单独开启“显示短信预览（本设备）”，显示发件人和最多 200 字的正文摘要，点按可进入对应会话。预览通过 Web Push 加密传输，锁屏上的实际显示由 iOS 通知设置控制。已经订阅的设备需要在设置中主动开启预览。
- 点按短信气泡时，时间、SIM 与状态合并到现有的信息来源行，避免重复显示。
- 长按短信会浮起原气泡，并提供“拷贝”和“转发”。靠近屏幕底部时菜单向上展开，长短信保持文字比例，滑动取消和快速关闭重开时会恢复原气泡。手指长按不自动选中菜单项，键盘操作仍显示焦点。
- 调整输入框与 iPhone 键盘的衔接，减少键盘展开、收起时页面跳动。

使用与现有安装相同签名的 APK 覆盖更新，可保留配对和应用数据。更新 Android 应用后，从 iPhone 多任务界面关闭主屏幕应用，再从主屏幕重新打开，以加载新网页资源。

验证包括前端长按、键盘焦点、通知预览及 Android 构建检查。已在已连接的 Android 手机上覆盖安装 0.8.8，并核对本机 HTTPS 服务提供的新网页资源。通知预览及点按进入会话曾由用户在 iPhone 上实测；0.8.8 的长按视觉细节仍需在 iPhone 上确认。

## English

SMS Connect Assistant 0.8.8 updates notifications and chat interactions in the iPhone Home Screen app.

- Notifications remain generic by default. Each iPhone can opt into “显示短信预览（本设备）” to show the sender and up to 200 characters of message text, then open the conversation on tap. Web Push encrypts the preview in transit. iOS notification settings control what appears on the Lock Screen. Existing subscriptions require an explicit opt-in.
- Tapping a message bubble now combines time, SIM and status with the existing source line instead of repeating them.
- Long-pressing a message lifts the original bubble and offers Copy and Forward. The menu opens above messages near the bottom edge. Long text retains its proportions, and cancelling a gesture or reopening the menu restores the source bubble. Touch does not preselect an action; keyboard navigation retains visible focus.
- The composer follows the iPhone keyboard more steadily when it opens and closes.

Install an APK signed with the same key over the existing version to preserve pairing and app data. After updating Android, close the iPhone Home Screen app from the app switcher and reopen it from the Home Screen to load the new web assets.

Validation covers browser checks for long-press behavior, keyboard focus and notification previews, plus the Android build. Version 0.8.8 was installed on the connected Android phone, and its local HTTPS service served the new web assets. The user previously verified message previews and conversation navigation on iPhone; the 0.8.8 long-press appearance still requires an iPhone check.
