## 中文

短信互联助手 0.8.9 为 iPhone 主屏幕网页应用加入未读角标。

- 收到短信推送时，后台网页应用请求点亮主屏幕图标角标。打开应用后，角标会按已载入的未读会话数更新，全部已读时清除。
- 已开启短信预览的设备收到测试通知时，不增加未读角标。
- 在 iPhone「设置 → 通知 → 短信互联助手」中允许通知并开启「标记」，系统才会显示角标。角标接口只在已添加到主屏幕的网页应用中可用。

角标依赖 iOS 收到推送。普通提醒的旧订阅无法在后台区分空载荷测试通知，因此测试通知可能暂时点亮角标，打开应用后会按未读状态校准。iPhone 实机显示仍需验证。

## English

SMS Connect Assistant 0.8.9 adds an unread badge to the iPhone Home Screen web app.

- Incoming SMS push events request a Home Screen badge while the app is closed. When opened, the app sets the badge to the number of loaded unread conversations and clears it when none remain.
- Test notifications do not add a badge on devices with message previews enabled.
- Allow notifications and enable Badges in iPhone Settings → Notifications → SMS Connect Assistant. The Badging API is available to Home Screen web apps.

The badge depends on iOS receiving push events. Legacy generic subscriptions cannot distinguish an empty test push from an SMS push in the background, so a test may temporarily set the badge until the app opens and reconciles unread state. iPhone device appearance remains to be checked.
